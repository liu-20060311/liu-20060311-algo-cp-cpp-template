# liu-20060311-algo-cp-cpp-template — 学习模板与刷题计划

此分支 daily-templates 包含 C++ 算法竞赛/刷题的学习模板、每日打卡计划与示例题目。

主要内容：
- templates/cpp_template.cpp — 可直接编译的 C++17 解题模板
- notes/learning_plan.md — 12 周路线与学习说明（混合平台）
- schedule/daily_plan_2h.md — 针对 2 小时/天 的每日刷题计划（混合平台）
- daily_log.md — 每日打卡模板（Markdown）
- problems/ — 解题代码目录，文件以 `YYYY-MM-DD_platform_short-title.cpp` 命名

使用方法：
1. 切换到 daily-templates 分支查看文件：
   https://github.com/liu-20060311/liu-20060311-algo-cp-cpp-template/tree/daily-templates
2. 每日完成题目后，将代码放入 problems/，按文件命名规范，并在 daily_log.md 中记录复盘。
3. 提交时请写清 commit message：例如 `feat: solve [Two Sum] (LeetCode) — 45m — tags: array,hash`。

如果你需要我随后为 daily-templates 发起 Pull Request 合并到默认分支，或添加 GitHub Actions 自动打卡 workflow，请告诉我。
